     1→// EGX Financial Scanner — data model
     2→// Principles (from master spec):
     3→//  - Never invent financial data; every value keeps original label + source traceability
     4→//  - Raw financial values and derived/calculated metrics are stored SEPARATELY
     5→//  - Reports are versioned (restatements never destroy history)
     6→//  - Every uploaded document is hashed (SHA-256) for duplicate protection
     7→//  - Demo/synthetic data is always explicitly flagged (isDemoData)
     8→

    10→  provider = "prisma-client-js"
    11→}
